## 1. 符箓出战

- 上阵入口在 **角色页装备栏**（与傀儡编成板并列），**无件数上限**。
- 工坊只负责画符；预载 API 仍写入同一张 `character_talisman_loadouts` 表。
- **只要装备栏勾选**就算带入下一场；开战消耗全部已上阵符箓（含未生效的低效果张）。

### 1.1 同种类不叠加

机读键：`talisman_effects.yaml` 的 `stack_group`。同组：

1. 按 `magnitude` 从高到低排序。
2. **当前生效**取最高层。
3. 最高层若是有限次数（`duration_kind=attacks`）或有限回合（`rounds`），耗尽后回落到组内次高（通常是 `global`）。
4. **全局层不会被更低的有限层压下去**。
5. 组内每一张 **都会消耗**，不论是否为当前生效层。

拍板例子：

| 装备 | 生效 |
| --- | --- |
| 开战 +30% 攻 与 +15% 攻 | 只加 30%；两张都消耗 |
| +30% 攻（3 次攻击）与 +15% 全局 | 前三次 30%，之后 15% |
| +10% 攻（3 回合）与 +15% 全局 | 全程至少 15% |

实现：`app.domain.talisman_stack`；单测 `test_talisman_stack_and_status`。开战数值乘区仍待 **M8-D04** 接到引擎。

### 1.2 攻击性符箓

- **仅攻击行动**掷骰；**移动不算**；**目标是障碍不算**。
- 顺序：是否使用（`use_chance`）→ 是否命中（`hit_chance`）→ 符伤害/对敌效果 → 再走普攻命中-伤害。
- 实现：`offensive_talisman_allowed` / `roll_offensive_talisman`。引擎接入挂 **M8-D04**。

## 2. 异常状态（行动回合开始）

顺序：

1. 该异常本回合是否到期 → 到期则清除，不占行动。
2. 未到期：是否装备了「解除异常」功法 → 施法概率 → 解除是否成功。
3. **解除成功：消耗一次行动机会。**
4. **未触发功法：不消耗行动**，但结算异常效果。
5. 昏迷 / 眩晕 / 睡眠 / 魅惑：先算苏醒概率；苏醒则解除并 **耗尽本回合全部行动机会**。

效果分类：

| 分类 | 状态 | 行动 | 被打 | 其它 |
| --- | --- | --- | --- | --- |
| 异常 | 中毒 / 灼烧 | 可行动 | — | 回合伤害；吃异常抗 |
| 异常 | 溺水 / 麻痹 | （未写回合细则） | — | 仅登记 id；吃异常抗 |
| 异常 | 昏迷 | 无法行动 | 不醒 | 吃异常抗 |
| 异常 | 眩晕 | 每回合仅 1 次行动 | 不醒 | 吃异常抗 |
| 异常 | 睡眠 | 无法行动 | 会醒 | 敌方不优先打；嘲讽/光环失效 |
| 异常 | 魅惑 | 可行动但打友方 | 会醒 | 友方不可打该目标；嘲讽/光环失效 |
| 诅咒 | 减攻 / 减防 | 可行动 | — | 直接改战斗属性；吃暗抗 |

抗性分类与后续公式见 [`战斗系统完善设计.md`](./战斗系统完善设计.md)。实现：`app.domain.status_effects.resolve_status_turn`（溺水/麻痹尚未接入本函数）。完整功法「解除异常」与嘲讽 Phase B 仍挂 **M3-D03** / **M3-D06b**。
