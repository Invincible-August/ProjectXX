## ARCH 对齐（2026-08-14）

> 工程重构指针：[`统一实体类层次与重构方案.md`](./统一实体类层次与重构方案.md) · [`双轨整改与配置兼容方案.md`](./双轨整改与配置兼容方案.md)  
> **主线优先**：先 ARCH 夯实（S1），**暂缓抢跑 M8**；玩法数值与 HTTP 路由默认不变。

| 项 | 对齐 |
| --- | --- |
| 领域对象 | **不是** `Character` 子类；**平台服务**（Presence / WsHub）；与养成 OOP 正交 |
| 配置 | 经 ContentStore（`presence`）；测试可 `yaml_authority` |
| 战斗 | 仅门闸（助战/赛会出席等）；不参与 BattleUnitSeed 组装 |
| 增量 | 保持 online/offline 二元；勿把 Presence 塞进 Entity 树 |

> **要点**：Presence 是连线态门面，不是可参战行动体；ARCH 对齐仅作边界说明。

## 1. 定案

| 项 | 定案 |
| --- | --- |
| 粒度 | **角色**（`character_id`），非账号 |
| 权威 | 进程内 [`WsHubService`](backend/app/services/ws_hub_service.py)：≥1 条**已鉴权**且绑定该角色的 WS 连接 |
| 多标签 | 任一存活连接即在线 |
| 与 `Character.status` | **正交**（挂机/战斗等业务态 ≠ 连线态） |
| 门闸枚举 | 仅 **online / offline**（不做 AFK / 隐身） |
| 断线宽限 | `presence.yaml` → `grace_sec`（默认 **30**）：最后连接断开后短暂仍视为在线，扛刷新/弱网 |
| DEV 假定 | 仅 `app_env=development`；经 [`PresenceService.is_online_for`](backend/app/services/presence_service.py)；分用途可读遗留 YAML 键 |
| 推送 | `presence.changed` → 该角色的道友 + 同队成员（不向全服广播） |
| 多 worker | 本阶段单进程；Redis 扩散 → **PRESENCE-R01** |

## 2. 玩法契约

| 玩法 | 用途键 | 门闸 | 离线行为 |
| --- | --- | --- | --- |
| 道友列表 | `friends` | 展示 | 仅 UI；动作仍服务端校验 |
| 组队邀请 | `party` | 双方须在线 | 拒邀请；已入队可离线留队 |
| 面交 | `face` | `face_require_online` 时关键步骤双方在线 | 明确「不在线」类错误 |
| 化身助战 | `assist` | 读主人 presence | **离线自动借入**；**在线须确认** |
| 赛会 | `contest` | 既有 `presence_check` | 不改赛制 |

> 助战路径依赖真实在线语义；勿用全局 `dev_assume_online=true` 覆盖 assist，除非刻意测「在线须确认」分支。

## 3. 配置

[`backend/app/config_data/presence.yaml`](backend/app/config_data/presence.yaml)：

- `grace_sec`：断线宽限秒数；`0` = 立即离线并推送  
- `dev_assume_online`：全局 DEV 兜底（默认 **false**）  
- `dev_assume_by_purpose`：可选覆盖；未写时回落到：
  - `party` ← `chat.party_dev_assume_online`
  - `face` ← `trade.face_dev_assume_online`
  - `friends` ← `friends.dev_assume_online`
  - `assist` ← `friends.assist_dev_assume_online` 或 `avatar.friend_assist.assist_dev_assume_online`
  - `contest` ← `dao_lord.contest.dev_assume_online`

## 4. API / WS

- 门面：`PresenceService.is_online(id)`（含 grace，无 DEV 假定）  
- 门面：`PresenceService.is_online_for(purpose, id)`（+ 用途 DEV 假定）  
- 推送：`type=presence.changed`，payload `{ character_id, online, at }`  

前端：玩法壳须保持 WS；未连接则自己为离线，组队/面交/助战门闸与之一致。

## 5. 明确不做

- 隐身 / AFK / 「仅好友可见」  
- 纯 HTTP 心跳双轨在线  
- 跨进程 Redis Presence（登记 **PRESENCE-R01**）
