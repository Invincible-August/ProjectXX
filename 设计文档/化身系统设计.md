## 1. 定案与边界

### 1.1 一句话目标

每个角色 **只能凝练一个化身**。化身是 **修士**（可挂机、分配、突破），不是灵宠式随从；上阵仍占 **本体神识**，不能当第二个账号。功能随 **本体大境界** 解锁；强度受神识约束；元婴起有独立体力/日行动。

### 1.2 写死边界

| 做 | 不做 / 说明 |
| --- | --- |
| **永久 `max_avatars = 1`** | **取消**「多化身数量随境界增加」（原 M4-D01） |
| 功能按 **本体大境界** 查表解锁 | 禁止代码写死 `if major == "yuanying"` 散落业务；一律读 `avatar.yaml` / 后台域 |
| 元婴起化身独立 **体力槽** + 日行动上限 | 与本体体力可分表；可互传体力时走折扣表（见 §6） |
| 金丹即可上阵（**必须与本体同场**） | **取消独战**：编成必须含 `main`；化神不再开放无本体编成 |
| 修为互传保留；炼体度/制造业经验 **不可传**（对齐 GDD §10.4） | 互传 **打折/保留率** 可配置，后台可调 |
| 宗门/NPC 任务由化身独立接取（达标后） | 真宗门玩法挂 M7；本文先定契约与占位 API |
| 玩家可见：已解锁功能、体力、日行动、互传折扣预览 | 禁止隐性扣成 |

2. **下一级解锁预告**（下一档大境界将开放什么）；  
3. **体力**（若已解锁）：当前 / 上限 / 恢复说明 / 今日行动剩余；

### 1.6 v1.3 化身修士（2026-08-19 冻结）

> 代码未开工前以本节为验收口径。与旧文「独战 / 突破权在本体」冲突时 **以本节为准**。

#### 身份

化身更接近 **玩家修士子类**，不是灵宠/傀儡。差异写死：

| 化身有 | 化身没有 |
| --- | --- |
| 独立挂机三池、分配、境界突破 | 独立账号 / 第二个神识池 |
| 与本体同场上阵（占本体神识） | **独战**（棋盘无本体） |
| 功法修炼（专修口子见下） | 体质、品阶、灵宠槽、傀儡编成 |
| | 就任道主、轮回外环身份 |

领域类：养成走修士契约；开战仍带 `divine_sense_cost`。禁止把 `avatars` 做成第二张 `characters`（无 `user_id`、会员、道主、轮回加成表）。

#### 突破与双封顶

化身自有 `major_realm` / `realm_stage` / `realm_progress`。分配与突破复用本体规则，调用方 `actor=avatar`。凝练时拷贝当时本体大境界与小境，面板战力仍按约 50% 打底。

**相对本体（默认可超小境、不可超大境）**

- 必须与本体处于 **同一大境界**，除非授予 `avatar_lead_majors > 0`。
- 同一大境界内，化身小境可以高于本体（本体元婴初期、化身元婴大圆满可以）。
- 禁止化身大境界高于本体（本体元婴大圆满、化身化神初期 → 拒绝突破）。
- `avatar_lead_majors`：允许化身比本体高几个大境界，默认 `0`。功法/装备授予同一键（专修化身玩法只加这一条）。

**绝对硬顶（进不了轮回境 / 道主境）**

- 化身走 **常规修为链**（锻体～当前 `realms` 表末境；落地链到真仙，金仙～大罗随表扩）。
- **禁止道主境**（GDD §2.5）：不能就任道主、不能成为某条大道之主。化身可在自身真仙后独立悟道（本命道/道值与本体分池）；入口在化身页「悟道」。
- **禁止轮回境**（GDD §2.6）：化身不是轮回外环主体；轮回只结算本体。
- `max_major_realm`：常规修为允许的最高大境界 id，默认当前链末境（落地 **`true_immortal`**）。道主/轮回是身份与外环状态，**不是**本字段可填的 major id。
- 相对本体的大境界封顶（`avatar_lead_majors`，默认 0）仍然生效。硬顶后可继续囤修为，不可再跨境或转入上述身份。

**渡劫**：雷劫状态机只打本体。化身跨境 **不渡劫**（不进 `tribulation`）。原 M5-D07「化身独立渡劫」**取消**。

功能解锁仍只看 **本体** 大境界。

#### 轮回点与化身

- 轮回商店预留类目 **化身专项**（`effect` 走独立键，例如 `avatar_upgrade_*`；货架条目实现期再填）。专项只强化化身（凝练比例、化身体力、挂机效率等），**不**改本体 `initial_attr` / 成长。
- 专项加成记在 **本体侧**（轮回后化身行仍可 dissolve）；再凝练时套用。
- **禁止**：轮回结算时把本体 `permanent_bonus_on_settle` 的 `initial_attr` / `minor_growth` / `major_growth` 套到化身。化身 **不**像本体那样继承基础属性或叠成长属性。

#### 阵法助战锚点（方案 B）

- 预设存 `assist_anchor: {x, y} | null`。玩家在可部署区点一格放置/移动「助」虚位，不可与已有棋子重叠。
- 自己的化身仍在「化身」栏手动摆。客串化身 **不进棋子栏**。
- 有 `friend_assist` 活跃会话：开战把客串化身注入锚点；未设锚点 → 拒绝开战（提示先布置助战位置）。
- 无会话：锚点只显示虚位。PVP/赛会仍拒客串。

## 2. 术语

| 术语 | 含义 |
| --- | --- |
| **本体** | 角色正身；账号 / 轮回 / 就任道主 / 背包 / 体质 / 品阶 / 灵宠傀儡槽的唯一主体；真仙后可独立悟道 |
| **化身** | 每位角色唯一修士实例（表 `avatars` 一行）；可突破，但有双封顶（相对本体 + 绝对硬顶）；真仙后可独立悟道（不就任道主） |
| **功能解锁** | 由本体 `major_realm` 查 `feature_unlocks` 得到布尔能力集（不因化身超前而提前开） |
| **助战锚点** | 阵法预设中一格 `{x,y}`；有道友化身助战会话时客串化身自动落该格 |
| **探索代理** | 本体可继续挂机；化身以任务/地图行动代表玩家在外（真地图 → M9） |
| **互传保留率** | `received = floor(sent × retention_ratio)`；`1.0` = 不打折 |

> 本文「传送/互传」均指 **本体↔化身资源传递**（修为等白名单），不是地图瞬移技能。地图位移若未来需要，另开域，不与本折扣表混用。

## 4. 体力与日行动（元婴起）

### 4.1 模型

| 项 | 约定 |
| --- | --- |
| 字段 | `avatars.stamina` / `stamina_cap`（或 cap 纯配置、当前值入库） |
| 启用条件 | 本体具备 `feature.stamina` |
| 日行动 | `daily_actions_used` + 配置 `daily_action_cap`；按角色时区或服务器日重置 |
| 消耗 | 探索行动、接/交任务、部分工坊加速等（表 `action_costs`；**无** `solo_battle`） |
| 恢复 | 独立于本体：按 tick / 按时辰 / 每日回复（`recovery` 表）；**不**自动用本体体力填满 |
| 互传体力 | 若开放：走 §6 折扣表；默认可先 `allow_stamina_transfer: false` |

### 4.2 显性

面板展示：`stamina`、`stamina_cap`、`daily_actions_remaining`、`recovery_summary`（配置文案）、下次恢复 ETA（若有）。

### 4.3 未达元婴

不创建体力字段逻辑：相关 API 返回「未解锁」；前端不展示空槽以免误解。

编成 **永久必须含本体**。原 `solo_battle` 功能、无本体快照、开战扣 `solo_battle` 体力全部作废。探索代理改为「本体挂机 + 化身任务/地图」，不再依赖无本体编成。

### 5.2b 道友化身助战（化神+ · `friend_assist`）

| 规则 | 说明 |
| --- | --- |

## 6. 互传折扣（可配置 · ADM）

### 6.1 公式

```text
若 resource ∉ transfer.allow → 拒绝（现行 40052）
若未解锁 transfer_cultivation → 拒绝
gross = floor(amount)
fee_ratio = 1 - retention_ratio          # 或直接配 retention
net = floor(gross * retention_ratio)
net = max(0, net)
扣发送方 gross；接收方 +net
```

| 配置项 | 说明 | 示例 |
| --- | --- | --- |
| `transfer.retention_ratio` | 到账比例 | `0.8` → 传 100 到账 80 |
| `transfer.retention_by_major` | 可选按本体境界覆盖 | 化神 `0.9` |
| `transfer.min_amount` | 最小互传 | `1` |
| `transfer.summary` | 玩家可见说明 | 「互传损耗两成，可在规则中查看」 |

### 6.2 显性

- 互传 UI：**输入 → 预览到账与损耗**（服务端 `POST /avatar/transfer/preview` 或同接口 dry_run）。  
- 结果回包带 `gross` / `net` / `retention_ratio`。

### 6.3 不可传

继续拒绝：`body_tempering_points`、`crafting_exp`（及未来表 `deny`）。

## 10. API 方向

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/avatar/me` | 扩：`features[]`、`stamina`、`daily_actions`、`unlock_preview` |
| GET | `/avatar/features` | 当前解锁 + 下一档预告（显性） |

| POST | `/avatar/transfer/preview` | 预览 gross/net/retention |
| POST | `/avatar/transfer` | 实扣；回包含折扣审计 |
| POST | `/craft/start` | `actor=avatar` 时校验 `workshop_actor` |
| 编成保存 | `/formation/*` | 必须含本体；`assist_anchor` |
| GET | `/avatar/explore/status` | 桩 |
| POST | `/avatar/quests/*` | 桩；未开玩法不改进度 |
