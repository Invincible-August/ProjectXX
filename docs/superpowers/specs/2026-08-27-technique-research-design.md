## 1. 目标

玩家用空白卡生成类型卡再生成正式卡，把属性、效能镶进草稿，选定发动条件并确认至少一个词条后定稿。定稿后原创者可继续培养（基础加成、词条、功法阶）。别人通过师徒、秘籍或藏经阁得到的是**定格副本**，只能装备不能培养。

本期不填死数值曲线；凡涉及点数、概率、消耗的量，一律进 YAML 配置，第一期用可运行的占位默认值。

---

## 2. 对象与槽位

### 2.1 三种对象

| 对象 | 能否装备 | 能否培养 | 说明 |
| --- | --- | --- | --- |
| **草稿** | 否 | 创造过程中的操作 | 不进可装备列表；同一角色可同时有多份 |
| **原创功法** | 是 | 是 | 定稿后进入已学/可装备列表 |
| **习得副本** | 是 | 否 | 师徒 / 秘籍 / 藏经阁；内容定格 |

装备才占功法槽；未装备与官方已学功法一样待在可装备列表。

### 2.2 主功法 / 技法

与现行双角色一致：同一门不能同时占主功法格和技法格。

| 效能 | 技法 | 主功法 |
| --- | --- | --- |
| 攻击法术、增益法术、攻击武技、增益武技 | 可以 | 不可以 |
| 修为修炼、炼体修炼 | 可以 | 可以（装备时二选一） |

### 2.3 来源与署名

| 如何得到 | `source` | 署名 |
| --- | --- | --- |
| 自己定稿 | `research` | 自己为创作者 |
| 师傅传授 | `mentor` | 显示创作者 id（原创者，不是师傅本人，除非师傅就是原创者） |
| 使用秘籍 | `chance` | 显示创作者 id |
| 藏经阁条目 | `sect` | 显示创作者 id |

习得方功法界面必须能看到创作者署名。

## 3. 卡片

卡片只有属性、效能两条线。发动条件、基础加成、词条不是卡。

### 3.1 三步

```text
空白卡（可交易）
  → 使用：随机变成「仅类型」属性卡或效能卡（可交易，无具体内容）  【不失败】
  → 再使用类型卡：生成带具体内容的正式卡（不可交易，可镶嵌）      【不失败】
  → 镶嵌进草稿                                                    【可失败】
```

**类型概率（配置）**：第一期空白卡变成属性类型 / 效能类型各 50%。

### 3.2 正式卡内容

**属性正式卡**

- 按**当前使用者**的灵根抽取。
- 种数与具体属性都随机：至少 1 种，至多等于该角色灵根中的元素种类数，不重复，不能出现灵根没有的属性。
- **属性池**：角色 `spirit_root_tags` 与功法元素枚举的交集。元素枚举与现行功法一致：金、木、水、火、土、风、雷（不含「暗」）。无可用元素则不能生成属性正式卡。
- 一门草稿只镶一张属性正式卡：成功后整组属性锁定。

**效能正式卡**

- 一门草稿只镶一个效能。
- 六选一均匀随机（配置可改权重）：攻击法术、增益法术、攻击武技、增益武技、修为修炼、炼体修炼。
- 镶嵌成功后锁定。

### 3.3 镶嵌失败

- 这张正式卡消耗掉。
- 草稿保留；已成功镶上的另一项保留。
- 可再拿新的正式卡重试。
- 无保底。失败率进配置。

### 3.4 放弃草稿

放弃草稿**不退**已镶嵌消耗掉的正式卡。背包里未镶嵌的空白卡、类型卡、正式卡不动。

## 4. 草稿流程与定稿

### 4.1 顺序

1. 创建草稿（可并行多份）。
2. 镶嵌属性正式卡、效能正式卡（顺序不强制，两张都成功才能往下）。
3. 确认发动条件（两个框均可不选）。
4. 开启词条：至少确认装备 1 个词条；可修炼时另须推演并选定五层/大圆满奖励。
5. 玩家确认创造 / 定稿 → 写入已学列表，成为原创功法。
6. 基础加成可在定稿前或定稿后操作，**不是**定稿门槛。

### 4.2 定稿后锁死

属性、效能、属性限制、装备限制全部锁定。

之后只能：升级基础加成、词条（含重随）、突破功法阶、制成秘籍、师徒传授、放入藏经阁、**废除**。

废除：须先卸下本尊/化身装备中的该功法；只删除作者自己的已学条目与对应 `PrivateTechnique`；已制成秘籍、他人学会的副本、藏经阁条目与弟子传承**不受影响**。

### 4.3 功法阶

功法等级与功法阶是同一件事，名称与人物**大境界**相同（锻体、练气……）。

- **定稿一律从最低阶（锻体）起**，与人物当前境界无关；须逐步突破上来。
- 人物当前大境界 = 这门原创功法能突破到的最高阶（封顶）。
- 升级点是**累计门槛，突破成功也不扣点**。
- 每一阶的累计点门槛进配置（示意：锻体阶 10、练气阶 100，以 YAML 为准）。
- 突破另耗资源，可失败：失败只扣本次突破资源，升级点与当前阶不变。无保底。

### 4.4 可修炼层数 / 大圆满（与功法阶并行）

目录功法与自创均可标记 `cultivable`（自创默认 true，见 `technique_craft.default_cultivable`）。

- **层数**走大厅「资源分配」：学会/定稿起为 1 层，升至 10 层；再投入 `perfection_cost` 置 `perfected`（大圆满）。不可修炼功法仍可装备，但不进分配列表。
- **五层**：`level >= 5` 时生效 `tier5` 奖励 ATTR；**大圆满**额外生效 `perfection` 奖励 ATTR。奖励库在 `research.yaml` → `technique_craft.level_bonus_catalog`。
- **自创**：定稿前须对五层 / 大圆满各推演一次三选一，选定 id 写入 payload；缺一不可定稿。
- **卡片培养**（基础加成 / 词条 / `major_rank` 突破）仍走洞府研究室，与层数分配互不替代。

## 5. 发动条件

两个独立单选，均可空。

### 5.1 属性限制

- 候选项 = 本门已嵌属性 ∪「不选」。
- 不选 = 发动不检查属性。
- 选了则**谁装备谁检查**（含原创者轮回改灵根之后）。
- 研发当时不另卡创造者（当时灵根必覆盖已嵌属性）。

### 5.2 装备 / 载体限制

候选项：剑、刀、枪、拳套、弓、傀儡、化身、不选。

- 不选 = 无装备限制，也无该项加成。
- 选了必须处于对应状态才能发动（武器已装备；傀儡已启用/上阵；化身已上阵）。不满足则不能发动，满足则有配置表加成。
- 傀儡、化身与武器同一套规则，不是「改由载体当主施法者」。

## 6. 基础加成（仅原创功法）

- 六种效能都是攻击 / 防御 / 速度。
- 可反复加同一项。
- 次数按**整门功法**累计：第 N 次升级按第 N 次成本，与加的是攻还是防无关。
- **总次数上限** = 从锻体到当前功法阶，每阶 `ranks.*.base_upgrade_cap`（本阶新增次数，后台可配）之和，再加「创建时冻结的每阶额外次数 × 已达阶数」。
- 创建额外次数：`base_upgrade_create_bonus_per_rank` 按创建境界查表冻结。**法修**（法术/修为修炼）读人物 `major_realm`；**体修**（武技/炼体修炼）读炼体大境对照的 `unlock_major`，二者不混用。
- 法术、修为修炼：消耗修为向资源（配置）。
- 武技、炼体修炼：消耗炼体向资源（配置）。
- 每次成功升级提供升级点（点数表配置）。
- 培养 UI 展示「剩余可升级」与已用/上限。

## 7. 词条（仅原创功法可改；副本只读已选结果）

### 7.1 过滤

生成池只含与当前功法兼容的条目，至少：

- 法术不含武技专属；武技不含法术专属。
- 攻击类不含与定位冲突的纯防御向词条。
- 与已嵌属性冲突或当前效能无法生效的不出。
- 与发动条件冲突的不出。

词条目录与冲突表进 YAML。第一期至少各效能各有若干可三选一的占位词条。

### 7.2 栏位

- 定稿前至少 1 栏；必须确认装备 1 个词条才能定稿。
- **创建栏数 = 人物当前大境界**对应的 `ranks.*.affix_slots`（锻体 1 … 化神/真仙 4），写入草稿并冻结为 `create_affix_slots`；与功法阶（定稿仍从锻体起）解耦。
- **突破补位**：若当前栏数低于该功法阶的 `affix_slots`，补空位；升级窗可推演/选择空位（新位无阶强化）。
- **突破强化**：成功突破后，所有**已有**（已选）词条叠一层 `rank_boost`（数值 × `breakthrough_affix_bonus`）；新开空位为 0。
- 栏数目标 = max(创建冻结栏数, 功法阶栏数, 已有栏数)，永不缩栏。

### 7.3 三选一与重随

- 每栏独立：当前词条、重随次数、重随消耗、升级次数、升级消耗。
- 生成三个有效词条，玩家选一个。
- 词条带**稀有度**（灰/白/绿/蓝/紫/橙/红）：权重控制出现率（白绿蓝最多，灰紫次之，橙再次，红最低）；越高初始属性、升级加成与升级消耗越高。配置键：`technique_craft.affix_rarities` + `affixes.*.rarity`（后台域 research）。
- 未选定或已生效都可重随；无次数上限、无锁定；该栏重随次数越多越贵（配置曲线）。
- 已升级的词条重随后：该栏升级等级与成长归零，再出三个有效词条。
- 不保留已投入的升级资源。

### 7.4 词条升级

- 每次成功升级提高该词条数值，并提高下一次消耗。
- 可失败：只扣本次资源，词条仍在、等级不变。无保底。
- 成功升级提供升级点（配置）。

## 8. 流通

### 8.1 共同原则

传出的是**新对象**。原创者自己的功法仍在，仍可培养。习得副本不能培养、不能再制成秘籍。

### 8.2 秘籍

- 仅原创者可制；印制消耗高（配置）；印的是**制作当下**的完整状态快照。
- 秘籍物品署创作者 id，不可堆叠混版本（不同快照不同实例）。
- 使用成功并学会后，**这本秘籍消失**（一本一人）。
- 学习门槛：学习者大境界 **≥** 快照上的功法阶；低于不能学。
- 学到快照原值，**不打折**。

### 8.3 藏经阁

详细设计见 [`2026-08-29-technique-scripture-p3-design.md`](./2026-08-29-technique-scripture-p3-design.md)。摘要：

- 自研须先制成秘籍，**仅创作者**上缴；提交即扣书，审核拒绝退同快照书，通过入库并发贡献（YAML）。
- 变成门派永久条目（快照与署名一并入库）；同 `origin` 再缴经审核后**替换**快照。
- 本门弟子按条目学习：扣贡献（YAML），**不再消耗秘籍**；门槛与定格同秘籍；`source=sect`。
- 与现有 YAML 目录贡献兑换**并存**；目录真授予系统功法不在 P3。
- 第一期不做每日次数；贡献数额全部进 YAML。

### 8.4 师徒传授（不经秘籍）

- 仅师傅 → 已有师徒关系的弟子。
- 所需成功传授次数由「弟子大境界」与「功法当前阶」共同决定，差距越大次数越多（配置表）。
- **同一轮学会**：内容锁定为该轮**第一次传授**时师傅功法的状态；后续传授只加进度。
- 学会时：属性、效能与快照一致不打折。副本展示的功法阶与快照相同（用于以后再学、以及和秘籍一样的「阶」概念），**不**把阶改写成弟子自己的境界。打折只作用于数值：基础加成、词条数值、装备限制加成等。差越大折扣越高（配置）。
- 功法在弟子身上**唯一**（同一创作者署名 + 同一原创功法身份）。弟子境界提升后可再开一轮学习：重新快照师傅**此刻**状态，按新差距打折，**替换**旧副本；本轮所需时间/次数按配置大幅缩短。

师徒允许弟子境界**低于**功法阶（用更多次数 + 更深折扣）。秘籍不允许低于。

## 9. 与现行工程的边界

| 现行 | 本文 |
| --- | --- |
| M8 R2：材料会话、一次词条预览、定稿冻结词条 | 卡片三步 + 定稿后仍可培养词条/加成/阶 |
| `research_sessions` 单会话为主 | 多草稿并行；定稿后培养挂在 `private_techniques`（或等价表）而非一次性会话 |
| 升级不改词条集合 | 原创者可重随、升级词条 |
| `/cave/lab?mode=technique` | 仍为功法自研入口，交互按本文重做；玩家可见文案用「心法雏形 / 另开新篇」，开卡与秘籍在洞府储物，镶嵌走点格选择窗（属性/效能分流） |
| 审核池 `submit_review` / `40210` | 第一期保持占位，不因本玩法新开全服审核 |

战斗仍走已装备功法 → grants / ATTR。完整主动技能链仍属 M8-D03，第一期词条以 ATTR/已有功法字段能表达的为主。

## 11. 配置清单（第一期全部 YAML 占位）

必须可调、禁止写死在业务分支里：

- 空白卡类型概率；效能六种权重
- 属性抽取种数分布
- 镶嵌 / 词条升级 / 突破失败率
- 各阶：词条栏数、基础加成次数上限、累计升级点门槛（创建栏数读人物境界；突破补位读功法阶）
- 基础加成与词条升级的消耗曲线、升级点奖励
- 重随消耗曲线
- 突破额外消耗；已有词条突破强化 `breakthrough_affix_bonus`
- 制秘籍消耗
- 藏经阁：上缴奖励贡献、专精匹配加成、学习学费
- 师徒次数表、折扣表、再学缩短系数
- 装备限制加成幅度
